Every post gets two ranks, one per order, and EVERY post is rendered here, with the ones that do not belong to this page in the default order marked `hidden`. modules/components/home-sort.js then only has to reorder the cards and flip `hidden` for the chosen order. That is what keeps pagination correct in both orders: page 2 by update date is a different set of posts than page 2 by publish date, and a script that merely re-sorted the five cards on screen would get it wrong. Without JavaScript the switch stays hidden and the page is exactly the theme's: publish order, server-side pagination. Pinned posts lead in both orders.
