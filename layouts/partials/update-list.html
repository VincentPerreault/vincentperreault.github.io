"Recently Updated" now means what it says, as in upstream Chirpy: only posts that were actually revised after publication (see post-updated.html), newest revision first. The theme's version fell back to the publish date, so with no revisions it was just the home page again. The latest *posted* entries are still available, folded away below the list. Both lists (and the trending tags, see trending-tags.html) are native
: no script, keyboard accessible. "Recently Updated" starts open and "Recently Added" closed, unless it is the only list.
